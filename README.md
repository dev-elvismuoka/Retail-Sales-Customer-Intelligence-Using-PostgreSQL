# Retail-Sales-Customer-Intelligence-Using-PostgreSQL
End-to-end SQL data analytics project for Duka Smart Electronics. Includes database schema creation, real-world data analysis of 800+ orders, and strategic business recommendations.
The project evaluates customer spending habits, product profitability, sales growth, and customer retention to provide management with data-driven recommendations.

## Tools & Technologies
* **Database:** PostgreSQL 14+
* **Languages:** SQL (DDL, DML, Window Functions, CTEs, PL/pgSQL)
* **Tools:** psql / pgAdmin, Git, GitHub

## Repository Structure
* `README.md`: Project documentation and setup guide.
* `schema.sql`: Data Definition Language (DDL) statements for creating the `customers` and `orders` tables.
* `queries.sql`: 46 business queries ranging from basic filtering to advanced window functions, views, and custom functions.
* `insights.md`: Five strategic business recommendations based on the SQL analysis.
* `screenshots/`: Verification of database setup and key query results.
